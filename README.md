# Pre-Entrega 3 - Funciones e Integración de Lógica

## Proyecto
Simulador de rendimiento de jugadoras de fútbol 6.

## Qué hace
El usuario puede ingresar el nombre de cada jugadora y asignarle un puntaje del 1 al 10.
El simulador valida los datos, muestra una evaluación individual y al final calcula el promedio general del equipo.

## Requisitos cumplidos
- Mínimo 3 funciones.
- Uso de parámetros en las funciones.
- Uso de return.
- Uso de una función flecha.
- Invocación de las funciones.
- Uso de ciclos.
- Uso de condicionales.
- Interacción mediante prompt, alert y console.log.
- Archivo HTML enlazado correctamente con JavaScript.

## Archivos
- index.html
- main.js

## Cómo probarlo
1. Abrir index.html en el navegador.
2. Ingresar el nombre de una jugadora.
3. Ingresar un puntaje entre 1 y 10.
4. Elegir si se desea evaluar otra jugadora.
5. Revisar el resumen final.
6. Abrir la consola del navegador con F12 para ver también los resultados por consola.
